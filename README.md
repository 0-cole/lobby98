# Lobby 98

A multiplayer social deduction and arcade platform with a Frutiger Aero / PS3 XMB aesthetic.

## Features
- **4 Party Games**: Frequency, Word Spy, Chain, Echo
- **Arcade**: Memory Match, Minesweeper, Firing Range, Math Rush, Snake, Blitz
- **Deep Dive RPG**: Canvas-based dungeon crawler with skill trees, weapon forge, and bosses
- **Persistent Systems**: Accounts, cosmetic shop, fake stock market, global chat with moderation
